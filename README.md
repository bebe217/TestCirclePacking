### 수행 과제: 겹치지 않는 원그리기

수행과제는 코테의 DFS처럼 비슷한 유형의 방법들이 있을 것 같아 구글링 후 Circle Packing이라는 키워드를 얻었습니다.
예전에 가끔 보던 알고리즘 교육 유튜브인 The Coding Train에서 해당 키워드로 검색하여 힌트를 얻어 과제를 시작하였습니다.

1. 뷰의 화면크기를 기반으로 원 배열을 생성합니다.
2. 원을 만들때 화면 안에서 랜덤으로 좌표값을 생성합니다.
3. 색상은 hue 값의 16개 색 배열에서 원의 index기반으로 순회하며 가져옵니다.
4. 원의 반지름은 랜덤으로 초기화해 줍니다.
5. 원을 생성할 때 기존 생성된 원들과의 거리를 구한 후에 겹치는 원이 있을 경우 두원이 접하게 되는 반지름을 구해 넣어줍니다.
6. 겹치는지 여부는 거리 < 두원의 반지름합 값으로 구합니다.
7. 새로 넣어줄 반지름이 음수(거리 - 상대 원 반지름)일 경우 기존원 내부에 좌표가 찍힌것이니 제외합니다.
8. 초기 반지름은 생성이 진행될수록 작게 생성하여 겹치는 횟수를 줄이도록 하였습니다.
9. 랜덤좌표를 생성해 확인하는 방식이라, 빈공간이 메꿔질때까지 수행하면 오랜시간이 걸려 2천개까지 원을 생성하였습니다.
